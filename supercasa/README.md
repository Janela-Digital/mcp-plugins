# SUPERCASA para Claude


## Install from the repository (Claude Code)

Repository: [Janela-Digital/mcp-plugins](https://github.com/Janela-Digital/mcp-plugins).

Run in Claude Code:

```text
/plugin install supercasa --marketplace Janela-Digital/mcp-plugins
```

Encontre imóveis em Portugal, consulte detalhes e filtros disponíveis e obtenha orientações sobre o SUPERCASA.

## Instalar no Claude.ai para experimentar

1. Abra Customize > Plugins no Claude.ai.
2. Use a opção de carregar um plugin personalizado e selecione o ZIP SUPERCASA.
3. Confirme a instalação, ative o plugin e conclua a ligação ao SUPERCASA quando solicitada.
4. Abra uma conversa e selecione a skill SUPERCASA através de / ou do botão +, se necessário.

Não é necessário publicar o plugin num diretório para experimentar na sua conta. A instalação está sujeita às permissões e políticas da sua conta ou organização.
Experimente:

- «Procura apartamentos à venda em Lisboa até 350 000 euros.»
- «Que filtros posso usar nesta pesquisa?»
- «Mostra os detalhes do segundo imóvel.»
- «Como publico um imóvel no SUPERCASA?»

Os resultados incluem ligações para os anúncios no portal. Quando os cartões não estiverem disponíveis, são apresentados em texto.

## Alertas e contacto

Pode pedir «Cria um alerta para esta pesquisa» ou «Quero contactar o anunciante deste imóvel».

Estas ações exigem uma conta SUPERCASA e uma ligação autenticada. Siga o processo de autenticação apresentado pelo Claude e confirme os dados da ação antes do envio. Nunca introduza a sua palavra-passe ou códigos de acesso na conversa.

Aguarde a confirmação do SUPERCASA para saber se o pedido foi concluído. Se ocorrer um erro, consulte o resultado antes de repetir o pedido.
