# SUPERCASA for Claude

Find properties in Portugal, view listing details and available filters, and get help using SUPERCASA.

## Try it on Claude.ai

1. Open **Customize → Plugins** on Claude.ai.
2. Choose the option to upload a custom plugin and select the SUPERCASA ZIP file.
3. Confirm the installation, enable the plugin, and connect to SUPERCASA when prompted.
4. Open a conversation and select the SUPERCASA skill using `/` or the `+` button if needed.

You can try the plugin in your account before publishing it to a directory. Installation depends on your account or organization permissions and policies.

Try these requests:

- “Find apartments for sale in Lisbon for up to €350,000.”
- “Which filters can I use for this search?”
- “Show me the details of the second property.”
- “How do I list a property on SUPERCASA?”

Results include links to the listings on SUPERCASA. If cards are unavailable, the results appear as text.

## Alerts and advertiser contact

You can ask “Create an alert for this search” or “I’d like to contact the advertiser for this property.”

These actions require a SUPERCASA account and an authenticated connection. Follow the sign-in flow in Claude and confirm the details before submitting the request. Keep your password and access codes out of the conversation.

Wait for confirmation from SUPERCASA. If an error occurs, check the result before trying again.
